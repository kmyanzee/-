# Kinetic Motion Experiment

14개의 검은 직사각형을 사용자가 직접 독립적으로 드래그하여 수직선을 통과시키면, 통과한 부분만 실시간으로 상·하단 두 개의 수평선으로 깎여 나가는 인터랙티브 키네틱 모션 웹 실험 페이지입니다.

## 동작 사양
- **화면 구성**:
  - 순백색 배경(`rgb(255, 255, 255)`).
  - 좌측 및 우측에 고정된 2개의 얇은 검은색 수직선(`1px`).
  - 두 수직선 안쪽에 7개 행으로 마주보는 검은색 가로 직사각형 14개(왼쪽 7개 + 오른쪽 7개) 배치.
  - 화면 높이의 약 80% 이상을 점유하며, 중앙 마주보는 틈새는 16~20px로 밀착.
- **인터랙션 규칙**:
  - **자동 애니메이션 배제**: 페이지 로드 시 정지 상태 유지, 사용자가 직접 드래그해야만 이동.
  - **행별 독립 및 좌우 완벽 미러 대칭 (Mirror Symmetry)**:
    - 7개의 행은 서로 완전히 독립적으로 작동함.
    - 같은 행의 좌측 막대와 우측 막대는 단일 공통 상태(`rowState`)를 100% 공유하여, 한쪽을 드래그하면 반대쪽 막대도 화면 중앙을 기준으로 정확한 미러 대칭으로 함께 연동 이동함.
    - 드래그 도중, 정지 시, 텍스트 reveal 이후 전 과정에서 **같은 행 좌우 막대의 남은 검정 면 길이(`remainingWidth`)가 항상 1px의 오차도 없이 완벽하게 동일**하게 유지됨.
  - **단방향 이동 제한 및 대칭 전진**:
    - 좌측 바: 좌측 방향(←)으로 전진.
    - 우측 바: 우측 방향(→)으로 전진.
  - **드래그 연동 및 위치 보존**:
    - Pointer Events(`pointerdown`, `pointermove`, `pointerup`)를 통해 마우스 및 터치 완벽 대응 (같은 행의 어느 쪽을 잡아도 해당 행이 대칭 연동).
    - **미세 절삭 스텝 스내핑 (`10px`)**: 연속적인 부드러운 이동 대신 10px 단위로 quantize/snap되어, 양쪽 바의 이동·면 절삭·상하 두 선 및 텍스트 reveal이 미세하게 탁탁 끊기며 단계적으로 갱신됨.
    - **실시간 1:1 드래그 추종 및 문턱(`6.5px`) 절삭 저항감**: 시간 지연(lag) 없이 마우스 포인터의 속도를 실시간 1:1로 즉각 추종하며, 각 10px 스텝 내에서 문턱(6.5px)에 도달하기 전까지는 양쪽 바가 수직선 방향으로 약 2.5px 점진적으로 눌리며 걸림 상태를 유지하다가, 문턱 통과 시 다음 10px 위치로 뚝 전환됨.
    - **절삭 직후 미세 반동 (Recoil / `3.5px`)**: 새로운 step으로 뚝 깎여 넘어가는 순간 좌우 막대가 각각 진행 방향 반대쪽(화면 안쪽)으로 3.5px 순간 튕겼다 60ms 내에 정착하는 절삭 저항감 및 반동 리듬 구현.
    - **행별 동일 최대 드래그 거리 Clamp (100% Reveal 한도)**: 같은 행의 좌우 막대는 완벽히 동일한 기준 길이 및 reveal 거리 한도를 공유하며, '날' 단어 행(2행, 5행)은 글자 끝 잘림 방지를 위한 여백(`endPadding: 16px`)이 좌우 모두 동일하게 적용되어 완벽한 대칭 유지.
    - **수직선 접합 보정**: 바 본체가 수직선을 완전히 지나치더라도 상·하단 선의 끝점은 동적 확장 로직을 통해 항상 고정 수직선(`targetLineX`)에 1px의 오차도 없이 맞닿아 연결 유지.
    - 드래그를 멈추면 해당 위치에서 즉시 정지하고 상태 유지 (자동 진행 일절 배제).
    - 큰 CSS easing, 관성(inertia), 출렁거리는 탄성 효과 일절 배제.
- **선 변환 및 텍스트 Reveal 규칙**:
  - 각 바가 자기 쪽 수직선을 통과할 때, 통과한 부분만 원래 바의 상단 및 하단 경계선(2개의 수평선)으로 실시간 변환.
  - 두 선 사이의 세로 중앙 공간에 각 행별 단어가 상단선과 하단선의 생성과 동시에 공간적(clip-path)으로 실시간 노출.
  - **단어 구성 (좌우 7행 동일)**:
    1. 누가
    2. 날
    3. 깎아내린다면
    4. 그냥
    5. 날
    6. 조각한다고
    7. 생각할게
  - **텍스트 정렬**:
    - 왼쪽 7개: 우측 정렬(`right-aligned`), 텍스트 오른쪽 끝이 왼쪽 수직선 방향을 바라봄.
    - 오른쪽 7개: 좌측 정렬(`left-aligned`), 텍스트 왼쪽 끝이 오른쪽 수직선 방향을 바라봄.
  - **공간적 Reveal 방향**:
    - 왼쪽 바: 왼쪽으로 드래그할 때 수직선(오른쪽)에서부터 왼쪽 방향으로 통과 길이만큼 노출.
    - 오른쪽 바: 오른쪽으로 드래그할 때 수직선(왼쪽)에서부터 오른쪽 방향으로 통과 길이만큼 노출.
    - 수직선 통과 전에는 텍스트 노출 안 됨(검은 면만 유지).
    - 드래그를 멈추면 선과 텍스트 reveal도 즉시 그 위치에서 멈춤.
    - Opacity/Fade-in 애니메이션 일절 배제하고 순수 공간적 clip-path로만 드러남.
  - **타이포그래피**:
    - 서체: Google Fonts `Noto Serif KR`
    - Font Weight: `400` (Regular)
    - 크기: 상·하단 수평선 사이 높이의 약 80~85%를 점유하며 상하 미세 여백 보존.
    - 단일 통일 font-size: 모든 단어에 동일한 크기를 적용하며 긴 단어("깎아내린다면", "조각한다고")도 줄바꿈 없이 한 줄 유지.
    - Letter Spacing: `-0.04em`으로 밀도감 있는 타이포그래피 구현.
    - **세로 midpoint 정렬 보정**: Noto Serif KR 서체의 폰트 메트릭 편차를 보정(`transform: translateY(-0.061em)`)하여, 텍스트 박스 기준이 아닌 실제 렌더링된 글자 잉크 영역의 수직 중앙이 상·하단 두 선 사이 높이의 정확한 midpoint에 위치하도록 상·하단 여백을 1:1로 일치시킴.
- **장식 배제**:
  - CSS transition, 자동 easing, 그림자, 그라디언트, 파티클 등 일체의 불필요한 효과 배제.
